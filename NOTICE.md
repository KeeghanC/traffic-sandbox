# Source attribution

Traffic Sandbox is a new application developed from the ideas and traffic-demo
structure of Keeghan Campbell's TrafficSimulator project, specifically the
`chaoticroading` version at `f708c3015c7222edb3af79d33d0afea304b05fd4`.

The original project is preserved separately. This repository contains a new
simulation model and desktop interface with procedural Java2D artwork; it does
not include the original repository history, university forms or generated
textures. The car-following model uses the conventional Intelligent Driver
Model (IDM) structure with a conservative numerical gap safeguard.
